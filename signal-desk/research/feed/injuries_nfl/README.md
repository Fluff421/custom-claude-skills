# NFL injuries feed layout

One folder per report date (America/Chicago): `injuries_nfl/YYYY-MM-DD/`.
Inside: one small CSV per team (`<team-slug>.csv`) plus `_manifest.csv` with team, game, file, data_rows, report_status.

Rules
- Source: https://www.nfl.com/injuries/ only. A blank Injuries column is not "healthy"; every listed player has a practice status.
- Only a section reading "No Injuries Reported" may use report_status=no_injuries_reported (one row, blank player).
- Write one team file per push, then read it back from GitHub and compare the row count with the page and the manifest.
- Mark rows verified only after that read-back; otherwise assumed.
- Daily runs: write only new or changed team files; if nothing changed, log one line in ops/.

2026-10-29 baseline was generated by `signal-desk/research/tools/nfl_injuries_snapshot.py` (parses the page HTML; 28 teams, 279 player rows plus 1 Seattle no-injuries row).
The earlier single-file CSVs were removed because they were truncated; the original 2026-10-28 file remains in git history at commit 7e37468 and contained known errors.
